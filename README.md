Громкость — окно у трея для отдельных программ Windows и отдельных сайтов в браузере. У каждой программы и у каждого разрешённого сайта свой коридор и своё усиление. Остальной звук компьютера не трогается.

Коридор задаётся двумя границами, от −60 до 0 дБ. Тише нижней границы звук поднимается к ней, громче верхней — прижимается к ней, между ними остаётся как есть. Усиление — запас от 0 до 600 % поверх коридора, в том числе выше обычных 100 % Windows.

Из окна программу или вкладку можно запустить и поставить на паузу, скрыть, закрепить в избранном и поменять местами. Скрытое из списка пропадает и перестаёт обрабатываться: играет своей обычной громкостью. Вкладки одного сайта собраны под ним. Сайт попадает в список только после согласия: по умолчанию расширение им не управляет и спрашивает один раз, когда страница может звучать.

Окно не висит на панели задач. Его открывают из трея или сочетанием клавиш, по умолчанию Ctrl+Alt+G.

## Запуск

Windows 10 или 11. Из папки проекта:

```bat
start.bat
```

Скрипт ставит зависимости из `requirements.txt`, если их ещё нет, и запускает `pyw -3 backend\volume.py`. Интерпретатор — `py` и `pyw`, не `python`.

Окно без рамки и без кнопки на панели задач. Открывается из трея и по Ctrl+Alt+G. Сочетание меняется в настройках. Повторное нажатие или клик мимо окна закрывает его.

Настройки лежат в `%LOCALAPPDATA%\Gromkost\gromkost.db`.

## Окно

Интерфейс собирается в `frontend\dist`, оттуда его берёт pywebview.

```bat
npm --prefix frontend install
npm --prefix frontend run build
```

После сборки программу нужно перезапустить: остановить процесс `volume.py` и снова запустить `start.bat` или `pyw -3 backend\volume.py --background`. Если старт упал, рядом с `backend\volume.py` появляется `volume.log`.

## Расширение

Папка `extension` — расширение Manifest V3. Его ставят вручную: `opera://extensions` или `chrome://extensions`, режим разработчика, «Загрузить распакованное».

Управление сайтом по умолчанию выключено. Если страница может играть звук, расширение спрашивает один раз. Сайт — это хост без `www`, без пути и без параметров: `youtube.com/watch?v=…` и `www.youtube.com` — один сайт.

После правки расширения на странице расширений нажимают «Обновить» и перезагружают уже открытые вкладки. Разрешённые сайты при этом не сбрасываются.

## Звук

Обычная программа приглушается в микшере Windows до 1 %. Программа забирает этот поток, применяет коридор и усиление и играет результат в текущее устройство. Выше 100 % можно подняться потому, что исходная сессия не может быть громче 100 %, а обработанная копия — может. Скрытая программа в эту обработку не идёт.

Браузер целиком не приглушается: иначе все сайты звучали бы одним потоком. Коридор вкладки считает `extension\hook.js` ещё до скриптов страницы. Простой `<audio>` и `<video>` забирает `extension\page.js`. Плеер, который страница уже ведёт через `AudioContext`, второй раз не забирается: его слышит перехват выхода.

Приложение и расширение на этой же машине говорят по `http://127.0.0.1:47921`. Команда старта и паузы приходит сразу, список вкладок — когда вкладка изменилась. Команда не переключает активную вкладку браузера.
